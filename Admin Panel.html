Admin Panel — мини‑флоу для тренера (первый запуск)
Коротко: последовательность действий для быстрого старта — от сбора упражнений до назначения программ и контроля питания. В основе логика: упражнения → тренировки → программа → клиент → назначение + подписки → контроль питания и прогресса. Этот флоу поможет настроить базу и начать работать с клиентами уже в первый день.

1. Добавить упражнение — сначала создаём библиотеку
Смысл: библиотека упражнений — ядро системы. Оттуда вы собираете тренировки, повторно используете элементы и стандартизируете технику для клиентов.
Открой раздел «Упражнения»
Все упражнения хранятся в одном месте — удобно искать, фильтровать по мышечной группе или уровню сложности.
Нажми «Добавить упражнение»
Создайте новую карточку: укажите название и, по возможности, подробное описание техники.
Загрузите видео
Кнопка «Загрузить видео» позволяет прикрепить демонстрацию — это ускорит усвоение техники клиентом.
Создать
После заполнения нажмите «Создать». Минимум — название; описание и видео рекомендуется добавлять сразу.

Совет: используйте стандартизированные названия и теги (мышечная группа, оборудование, уровень), чтобы потом быстро фильтровать.
2. Создать тренировку — шаблон одного занятия
Смысл: тренировка — это готовый шаблон, собранный из упражнений. Шаблоны экономят время и гарантируют единообразие программ.
Открой «Тренировки» → «Добавить тренировку»
Придумайте понятное название (например: «Силовая — Ноги 45 мин»).
Добавь упражнения из списка
Выбирайте из вашей библиотеки — порядок можно менять перетаскиванием.
Задай план для каждого упражнения
Укажите: подходы, повторы, вес (если нужно), время и комментарии (техника, альтернативы).
Сохрани тренировку
Шаблон доступен для добавления в программы и назначения клиентам.

Хорошая практика: добавляйте варианты упражнений для разного оборудования и уровня клиента.
3. Добавить тренировки в программу — формируем путь клиента
Смысл: программа — это цепочка тренировок в определённом порядке, рассчитанная на курс или цель клиента.
Открой «Программы» → «Добавить программу»
Создайте контейнер для тренировок: укажите длительность и цель (например: набор массы, похудение, выносливость).
Добавь тренировки в порядке
Перетаскивайте шаблоны тренировок в нужную последовательность — учитывайте нагрузку и дни восстановления.
Сохрани и опубликуй
Программа готова к назначению клиентам; можно оставлять заметки и рекомендации по питанию.
Подсказка: создавайте варианты программы (начальный/промежуточный/продвинутый), чтобы быстро переключать их под уровень клиента.
4. Создать клиента — профиль и доступ
Смысл: клиент должен быть создан в системе, чтобы получать тренировки и отслеживаться. Телефон используется как логин, поэтому важно ввести корректный контакт.
Шаги
  1. Открой «Администрирование» → «Пользователи»
  1. Нажми «Создать пользователя»
  1. Укажи имя и телефон (логин)
  1. Сохрани и передай данные
Рекомендуется: заполнять дополнительные поля (возраст, уровень, противопоказания), чтобы потом корректно подбирать нагрузку и питание.

Без корректного телефона клиент не сможет войти — проверьте формат перед сохранением.
5. Назначить клиенту программу — моментальная видимость плана
Смысл: после назначения клиент сразу увидит свою тренировку при активной подписке. Есть два удобных пути назначения — из программы или из карточки клиента.
Вариант 1 — из программы
Открой нужную программу → нажми «Назначить» → выбери клиента → подтверди. Новая программа заменит старую, если она была активна.
Вариант 2 — из карточки клиента
Открой «Люди» → выбери клиента → блок «Программы» → выбери программу и назначь.

Совет: добавляйте стартовую дату и заметки (цель, ограничения) прямо при назначении.
6. Назначить клиенту подписку — доступ к тренировкам
Смысл: без активной подписки клиент не увидит свои тренировки. Подписка контролирует доступ и срок обслуживания.
Открой «Администрирование» → «Пользователи»
Найдите клиента и нажмите «Изменить подписку».
Выбери дату окончания
Укажите дату, после которой доступ будет закрыт (в день окончания с 00:00 подписка считается неактивной).
Сохрани
Проверьте, что напоминание о продлении настроено, чтобы не оставлять клиента без доступа.

Рекомендация: уведомлять клиента за 7 и 1 день до окончания подписки.
7. Отправить новость — уведомления для клиентов
Смысл: новости позволяют оперативно информировать клиентов о изменениях, акциях или важных событиях. Используйте сегментацию, чтобы не спамить всех подряд.
Создать новость
Открой «Новости (управление)» → нажми «Создать новость» → заполни заголовок и текст.
Выбери аудиторию
Можно «Отправить всем» или выбрать конкретных клиентов/группы.
Опубликовать
Нажмите «Опубликовать» — новость уйдёт в push/email/внутренние уведомления (в зависимости от настроек).

Хорошая практика: краткий заголовок + один основной CTA; прикрепляйте изображение для лучшего вовлечения.
8. Посмотреть питание клиента — контроль по дням
Смысл: тренер может отслеживать питание клиента, видеть фото приёмов пищи, калории и историю по дням — это важно для корректировки рекомендаций и достижения целей.
Как открыть
  • Открой «Люди» → выбери клиента
  • Перейди в раздел «Питание»
В разделе отображается: список приёмов пищи, суммарные калории за день, прикреплённые фото и история изменений.
Что можно увидеть
  • Что клиент ел (с описанием)
  • Калории и макросы (если ведутся)
  • Фото приёмов пищи
  • Историю по дням с возможностью комментариев

Совет: оставляйте короткие корректировки и рекомендации прямо под фото — так клиент быстрее применит правки.
9. Результаты и прогресс — обзор динамики клиента
Смысл: видеть выполнение плана и изменения в показателях — ключ к адаптации тренировок и удержанию клиента. Дашборд объединяет данные по тренировкам, упражнениям и общему обзору по базе клиентов.
Тренировки: план vs факт
Сравнение запланированных занятий и фактически выполненных — помогает понять дисциплину и отклонения.
Прогресс по упражнениям
Статусы: рост / без изменений / регресс. Отмечайте упражнения, требующие внимания или замены.
Обзор базы
Индикаторы по посещаемости, активным подпискам и списку клиентов без программ — для приоритизации работы.
Рекомендация: делайте еженедельные заметки в профиле клиента и пересматривайте программу при признаках стагнации или регресса.
